Readings

GET
/api/v1/readings/

Query canonical readings. Params: sensor, pollutant, start, end, quality.

Auth: Researcher API key or session
POST
/api/v1/readings/

Submit live readings from a sensor. Body: serial_number, timestamp, readings[].

Auth: Sensor API key
GET
/api/v1/sensors/

List all sensors. Params: status, site.

Auth: Public
GET
/api/v1/sensors/{id}/

Sensor detail + recent PM2.5 stats.

Auth: Public
POST
/api/v1/sensors/register/

Register a new sensor. Body: serial_number, model, site, is_indoor, …

Auth: Sensor API key
GET
/api/v1/charts/sensor/{id}/timeseries/

Time-series chart data. Params: pollutant, start, end.

Auth: Public
GET
/api/v1/charts/national/summary/

Latest PM2.5 per sensor + WHO guideline comparison.

Auth: Public

Example: Submit readings

curl -X POST /api/v1/readings/ \
  -H "X-API-Key: YOUR_SENSOR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "serial_number": "81432434001",
    "timestamp": "2026-01-15T08:30:00Z",
    "readings": [
      {"pollutant": "PM25", "value": 45.2, "unit": "µg/m³"},
      {"pollutant": "PM10", "value": 62.1, "unit": "µg/m³"},
      {"pollutant": "TEMP", "value": 18.5, "unit": "°C"},
      {"pollutant": "RH",   "value": 72.0, "unit": "%"}
    ]
  }'
