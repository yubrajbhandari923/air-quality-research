Quick reference

Single reading (live sensor, one timestamp):

POST /api/v1/readings/
X-API-Key: <your-key>
Content-Type: application/json

{
  "serial_number": "81432434001",
  "timestamp": "2026-05-29T08:00:00Z",
  "readings": [
    {"pollutant": "PM25", "value": 45.2, "unit": "µg/m³"},
    {"pollutant": "TEMP", "value": 18.5, "unit": "°C"}
  ]
}

Batch upload (offline catch-up, multiple timestamps):

POST /api/v1/readings/batch/
X-API-Key: <your-key>
Content-Type: application/json

{
  "serial_number": "81432434001",
  "readings": [
    {
      "timestamp": "2026-05-29T08:00:00Z",
      "measurements": [{"pollutant": "PM25", "value": 45.2, "unit": "µg/m³"}]
    },
    {
      "timestamp": "2026-05-29T08:01:00Z",
      "measurements": [{"pollutant": "PM25", "value": 47.1, "unit": "µg/m³"}]
    }
  ]
}

Valid pollutants: PM1, PM25, PM4, PM10, CO2, CO, SO2, O3, NO2, CH2O, TVOC, TEMP, RH, BARO, NC05, NC1, NC25, NC4, NC10
