# Project Rules

You are assisting with air quality research.

## Priorities

- reproducible science
- clean modular code
- publication-quality figures
- accurate GIS handling
- preserve raw datasets

- use pandas/geopandas

- label units clearly
- include legends
- use readable color scales
- use publication-quality styling

## Workflow Rules

- never overwrite raw data
- document transformations
- keep notebooks clean
- modularize repeated logic
